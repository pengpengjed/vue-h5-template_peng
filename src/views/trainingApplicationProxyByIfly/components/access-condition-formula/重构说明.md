# 准入条件公式组件重构说明

## 重构内容

根据UI设计图和需求文档，对准入条件列表组件进行了全面重构，主要实现以下功能：

### 技术实现
- 使用 `div` 布局替代 `van-cell`，实现更灵活的UI设计
- 使用 `van-dialog` 组件实现确认满足弹窗
- 使用 `csFileUploadPopup` 组件实现文件上传功能
- 使用 `this.$toast()` 显示提示信息
- 使用 `require()` 动态加载图标资源

### UI布局设计
- **第一行**：条件序号在左边（带主题背景色），图标在序号右上角，条件内容在右边
- **第二行**：操作按钮独立一行，所有按钮使用 `type="info"`，取消确认使用 `plain` 样式
- **第三行**：文件图标 + 附件名称 + 重新上传按钮

### 1. 条件状态可视化

- **通过条件**：显示绿色边框和文字，使用 `icon-pass.png` 图标
- **不通过条件**：显示红色边框和文字，使用 `icon-fail.png` 图标  
- **手工确认**：显示橙色边框和文字，使用 `icon-question.png` 图标

### 2. 交互功能

#### 确认满足功能
- 不满足的条件显示"确认满足"按钮
- 点击后弹出二次确认弹框，提供两个选项：
  - **不上传**：直接确认条件满足，状态变为手工确认
  - **上传**：需要上传附件材料

#### 文件上传功能
- 支持格式：PDF、DOC、DOCX、XLS、XLSX、PNG、JPG、JPEG、BMP
- 文件大小限制：10MB以内
- 仅支持上传1个文件，再次上传会替换原文件
- 上传后显示附件名称，可点击预览

#### 取消确认功能
- 手工确认的条件可以取消确认
- 取消后删除已上传材料，状态恢复为不通过

### 3. 图标点击提示
- 点击 `icon-question.png` 图标显示提示："系统无法校验该准入条件，人工确认满足"

## 状态定义

```javascript
// 条件状态
condition.status = 'success'  // 通过：绿色，显示 icon-pass.png
condition.status = 'error'    // 不通过：红色，显示 icon-fail.png，显示"确认满足"按钮
condition.status = 'manual'   // 手工确认：橙色，显示 icon-question.png，显示"取消确认"按钮

// 附件相关
condition.hasAttachment = true/false  // 是否需要上传附件
condition.attachment = { name: '文件名.pdf', url: '文件地址', file: File对象, path: '路径' }  // 附件信息
```

## 事件说明

### 对外事件
- `confirm-satisfaction(condition, hasAttachment)` - 确认满足条件
- `cancel-confirmation(condition)` - 取消确认
- `upload-attachment(condition, file)` - 上传附件
- `preview-file(file)` - 预览文件

### 使用示例

```vue
<access-condition-formula
  :data="conditionData"
  :ifModify="false"
  @confirm-satisfaction="handleConfirmSatisfaction"
  @cancel-confirmation="handleCancelConfirmation"
  @upload-attachment="handleUploadAttachment"
  @preview-file="handlePreviewFile"
/>
```

## 样式特性

- 条件项根据状态显示不同颜色的左边框
- 响应式设计，适配移动端
- 弹窗居中显示，支持覆盖层
- 文件上传区域拖拽样式

## 注意事项

1. 组件使用 `require()` 动态加载本地图片资源，确保图标文件存在
2. 文件上传使用项目现有的 `csFileUploadPopup` 组件，支持APP内和H5环境
3. 条件状态使用实际数据结构：`success`、`error`、`manual`
4. 确认弹窗使用 `van-dialog` 组件，符合项目UI规范
5. 提示信息使用 `this.$toast()` 方法，无需额外弹窗
6. 文件上传支持格式：`['pdf', 'doc', 'docx', 'xls', 'xlsx', 'png', 'jpg', 'jpeg', 'bmp']`
7. 文件大小限制：10MB
