# 准入条件列表样式设计说明

## 整体布局

采用全新的DIV布局设计，取代原有的van-cell组件，实现更灵活的UI展示。

## 条件项结构

每个条件项包含三个部分：

### 第一行：条件头部 (condition-header)
```
[条件序号背景块] + [条件内容文字]
    ↑右上角有状态图标
```

#### 条件序号容器 (condition-number-container)
- **位置**：左侧固定宽度60px
- **样式**：圆角矩形背景，带边框
- **颜色方案**：
  - 成功：绿色背景 `#10b981` + 绿色边框 `#94dcce`
  - 错误：红色背景 `#dc2626` + 红色边框 `#f0c6bb`
  - 手工：橙色背景 `#f59e0b` + 橙色边框 `#f0dcbb`

#### 状态图标 (condition-status-icon)
- **位置**：相对于序号容器，定位在右上角 `top: -2px, right: -2px`
- **尺寸**：16x16px
- **图标资源**：
  - `icon-pass.png` - 成功状态
  - `icon-fail.png` - 错误状态  
  - `icon-question.png` - 手工确认状态

#### 条件内容 (condition-content)
- **位置**：序号容器右侧，占据剩余空间
- **样式**：12px字体，深灰色 `#444444`，行高1.5
- **布局**：flex: 1，自适应宽度

### 第二行：操作按钮区域 (condition-actions)
- **显示条件**：非编辑模式且有操作按钮时显示
- **布局**：水平排列，8px间距
- **按钮样式**：
  - 统一使用 `type="info"`
  - 取消确认按钮使用 `plain` 样式
  - 小尺寸 `size="mini"`，自定义内边距和字体

### 第三行：附件信息区域 (condition-attachment)
- **显示条件**：手工确认状态且有附件时显示
- **布局**：水平排列，附件信息占据主要空间，按钮在右侧

#### 附件信息块 (attachment-info)
- **背景**：浅蓝色 `#ddeeff`
- **圆角**：4px
- **内容**：文件图标 + 附件名称
- **交互**：点击可预览文件

#### 文件图标 (file-icon)
- **资源**：`icon-file.svg`
- **尺寸**：15x15px
- **颜色**：蓝色主题

## 状态视觉设计

### 成功状态 (success)
- 序号背景：绿色 `#10b981`
- 边框：绿色 `#94dcce`
- 图标：✓ 绿色对勾

### 错误状态 (error)
- 序号背景：红色 `#dc2626`
- 边框：红色 `#f0c6bb`
- 图标：✗ 红色叉号
- 按钮：显示"确认满足"

### 手工确认状态 (manual)
- 序号背景：橙色 `#f59e0b`
- 边框：橙色 `#f0dcbb`
- 图标：? 橙色问号
- 按钮：显示"取消确认"、"上传"（如有附件需求）

## 响应式设计

- 适配移动端H5页面
- 序号容器固定宽度，内容区域自适应
- 按钮区域支持换行
- 附件信息区域支持长文件名显示

## 交互特性

1. **点击序号**：编辑模式下可添加到公式
2. **点击状态图标**：
   - 成功/错误状态：显示条件详情
   - 手工确认状态：显示toast提示
3. **点击附件名称**：预览文件
4. **按钮操作**：确认满足、取消确认、上传附件

## CSS类名规范

```css
.conditions-list                    // 条件列表容器
  .condition-item-wrapper          // 单个条件项包装器
    .condition-header              // 条件头部
      .condition-number-container  // 序号容器
        .condition-number          // 序号文字
        .condition-status-icon     // 状态图标
      .condition-content           // 条件内容
    .condition-actions             // 操作按钮区域
    .condition-attachment          // 附件信息区域
      .attachment-info             // 附件信息块
        .file-icon                 // 文件图标
        .attachment-name           // 附件名称
```

这种设计确保了良好的视觉层次，清晰的信息展示，以及流畅的用户交互体验。
